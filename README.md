# Pokédex

Projeto em Java para montar uma Pokédex, feito durante o curso na FIAP.

## Status

🚧 Em desenvolvimento. A classe `PokemonTO` está pronta e o `PokemonDAO` ainda está sendo construído.

## Estrutura

- `to/PokemonTO` — objeto de transferência com código, nome, altura, peso, categoria e data de captura.
- `dao/PokemonDAO` — guarda a lista de pokémons (em construção).

## Tecnologias

- Java
